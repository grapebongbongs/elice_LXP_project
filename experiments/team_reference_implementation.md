- `FEWSHOT_K=0`: 공개 세트 예시 검색은 기본적으로 꺼져 있다. 해당 모듈이
  사용하는 자료는 배포된 공개 세트이며, 새 채점 요청을 저장하는 캐시가 아니다.
- `EXP_DEBUG=0`: 실험용 진단 출력은 기본적으로 꺼져 있다. 제출 환경에서도
  이 기본값을 유지해야 한다.
- 본문 없는 메타데이터 로그와 운영진 API 환경 변수 사용을 유지한다.
  새 라이브러리나 외부 서비스, 모델 파일, 별도 생성 데이터셋은 추가하지 않았다.
