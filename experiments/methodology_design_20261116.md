# 참고 방법론 적용 설계 (2026-11-16)

사용자가 제공한 타 실험 기록을 현재 코드에 맞춰 구현했다. 기록에 나온
`17adfc1`은 이 저장소에 없으므로 해당 커밋의 복원이나 점수 재현은 아니다.
기존 수정 파일과 최고 점수 기록, submission.json은 유지한다.

## 요청 처리

- 튜터: 무의미 입력은 모델 없이 clarify. 검색은 기존 BM25를 유지하며 영어 번역
  검색은 기본 해제. 검색 1위로 answer 생성을 분류와 동시에 시작한다.
- 입력 분류와 단서 기반 경계 판정을 병렬 실행한다. 직접 지시 우회/교육적 인용,
  개인정보 탐색/자기 정보 공개, 사기 제작/예방, 과제 대행/학습 질문을 구별한다.
  튜터에만 수업 밖 제작 요청 경계를 추가한다. 단어는 호출 단서이며 차단 규칙이 아니다.
- 주 분류와 보조 판정이 충돌하면 명시적인 위험 판정을 우선한다. 개인정보/사기
  검사에서 normal이 나와도 별개의 모욕·비하 판정을 해제하지 않는다.
- 모욕·비하 유형 누락은 redirect로 보정하되, 주 분류에서 확인한 actionable은
  보존한다. 참고 문서의 광범위한 harmful→redirect 규칙을 그대로 적용하지 않았다.
- named-rule 검사는 질문에 붙인 규칙·기준·등급 이름이 검색 1위에 없을 때
  abstain 처리한다. 앞선 refuse/escalate/scaffold 결정을 덮지 않는다.
- answer는 제시된 섹션 안에서 quote가 **원문 부분 문자열로** 존재해야 한다.
  글자 bigram 유사도는 사용하지 않는다. 실패하면 재생성 없이 abstain 처리한다.
  인용 섹션의 검증된 quote 하나만 답 끝에 붙인다. 중복 및 4000자 초과는 피한다.
- 가드 답변 검증은 3회 병렬 호출한다. 실패·잘못된 grounded 형식은 투표에서
  제외하고, grounded 과반이 확정되면 남은 호출을 취소·회수한다. unsupported는
  근거 없음 표 중 구간 총길이가 가장 짧은 표의 원문 구간을 사용한다.
  유효 표가 2개이고 동률이면 grounded=false, 모두 실패하면 기존 fallback이다.
- 튜터 분류/생성 및 가드 입력은 8초 뒤 보조 호출을 시작한다. 가드 입력의
  보조 호출은 low 추론을 사용한다. 첫 유효 응답 후 남은 호출을 취소·회수한다.
  기존 요청 전체 25초 상한을 유지한다.

## 검증과 한계

`python -m unittest discover -s baseline/tests -v`로 원문 불일치, 인용 범위,
중복 첨부, 재생성 금지, 고정 응답, 투표 실패, 비동기 호출 취소 및 mock
64개 동시 API 응답을 검증한다. 테스트는 외부 LLM을 호출하지 않는다.

새 경계 판정·3표 검증·미리 생성은 모델 호출량을 늘린다. mock 동시성 검사는
실제 모델의 지연과 점수를 증명하지 않는다. 정식 성능 확인은 팀 런박스에서
동일 조건의 이전 버전/변경 버전을 짝 비교하고, 개별 스위치별로 효과를 측정해야 한다.
공개 자료의 해시 holdout을 유지하고, 실제 제출 평균으로 최종 판단한다.
이 변경 자체는 배포·정식 제출·최고 설정 승격을 수행하지 않는다.
